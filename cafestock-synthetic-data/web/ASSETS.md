# Local interface assets

- Manrope variable (Latin, weight axis): Fontsource distribution, originally by Mikhail Sharanda. SIL Open Font License 1.1; see FONT-LICENSE.txt. The font is self-hosted in manrope-latin.woff2.
- Lucide icons: retrieved with Better Icons through Iconify. License and copyright: ICON-LICENSE.txt. SVG paths are embedded as a symbol sprite in index.html; glyph fills are normalized to none for a consistent outline treatment. The favicon uses the coffee glyph.
- All charts use the existing CafeStock datasets and SVG generation; no stock imagery or external chart service is used.

The application makes no third-party font or icon requests at runtime.
